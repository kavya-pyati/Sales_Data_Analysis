# Sales Data Analysis

## 📌 Project Overview

This project analyzes sales data to identify patterns in product demand, revenue, customer ordering times, monthly sales, and city-wise performance.

The project demonstrates the use of Python and data analysis techniques to clean, analyze, visualize, and interpret sales data.

## 🎯 Objectives

- Identify the best-selling products.
- Find products generating the highest revenue.
- Analyze monthly sales trends.
- Compare sales across cities.
- Identify the busiest ordering hours.
- Examine the relationship between quantity sold and revenue.
- Identify the top 5 products by revenue.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
